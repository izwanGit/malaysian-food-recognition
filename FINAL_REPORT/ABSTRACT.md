# ABSTRACT

This project develops a Malaysian Hawker Food Calorie Estimation System that automates food recognition and nutritional analysis for seven popular hawker dishes: Nasi Lemak, Roti Canai, Satay, Laksa, Popiah, Kaya Toast, and Mixed Rice. The system employs a hybrid approach combining classical image processing with deep learning, featuring preprocessing through histogram stretching and noise filtering, food segmentation using Chan-Vese Active Contours, and dual classification modes using either Support Vector Machine or the lightweight SqueezeNet CNN architecture. Experimental evaluation demonstrates that SqueezeNet achieves 83.0% validation accuracy, significantly outperforming the SVM baseline at 39.4%. Portion estimation is accomplished through dynamic Food-to-Plate Ratio calculations that adjust base caloric values from the Malaysian Food Composition Database. A fully functional GUI developed using MATLAB App Designer integrates all modules into a cohesive dashboard, providing immediate dietary feedback including predicted food class, confidence score, portion size, and macronutrient information. The project successfully achieves all objectives of developing a dual-mode recognition system, implementing an integrated GUI prototype, and validating performance on Malaysian hawker food, demonstrating that deep learning is essential for handling the visual complexity of this culturally significant cuisine.
