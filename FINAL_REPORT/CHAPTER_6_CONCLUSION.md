# CHAPTER 6: CONCLUSION AND FUTURE WORK

This chapter summarizes the key achievements of the Malaysian Hawker Food Calorie Estimation System and outlines potential directions for future development. The project successfully demonstrated that combining classical image processing techniques with modern deep learning can produce a practical tool for automated dietary monitoring.

## 6.1 Conclusion

This project has successfully achieved all three objectives outlined in Chapter 1, demonstrating the viability of combining classical image processing techniques with modern deep learning approaches for automated dietary monitoring of Malaysian hawker food. The system addresses a critical public health need in Malaysia, where rising obesity rates coexist with a rich culinary heritage that includes UNESCO-recognized hawker food culture. By enabling automated recognition and calorie estimation, the prototype empowers users to make informed dietary choices without sacrificing their enjoyment of traditional cuisine.

The first objective was to develop a food recognition system using classical image processing techniques for preprocessing and segmentation, with dual classification options using either Support Vector Machine or Convolutional Neural Network. This objective was fully achieved through the implementation of a comprehensive MATLAB-based pipeline. The preprocessing module applies histogram stretching and noise filtering to normalize input images, while the Chan-Vese Active Contour algorithm accurately segments food regions from complex backgrounds. For classification, the system offers two modes: a Classical SVM pipeline that extracts handcrafted color histograms and GLCM texture features, and a Deep Learning CNN pipeline that leverages transfer learning with the SqueezeNet architecture. The experimental results in Chapter 5 demonstrated that the CNN achieved 83.0% validation accuracy compared to the SVM's 39.4%, validating the superiority of deep learning for this visually complex task.

The second objective was to implement a graphical user interface prototype that integrates the system for immediate dietary feedback. This was accomplished through the development of a fully functional GUI using MATLAB App Designer. As demonstrated in Section 5.2, the interface provides a cohesive dashboard with three functional zones: a Visualization Panel displaying Original, Processed, and Segmented images side-by-side; a Control Module for selecting the classification method and triggering analysis; and a Results Dashboard that presents the predicted food class, confidence score, portion size, and detailed nutritional information including calories, protein, and carbohydrates. The GUI successfully delivers immediate dietary feedback in a user-friendly format, supporting public health initiatives in Malaysia.

The third objective was to evaluate the system's performance on a subset of the Malaysia Food 11 dataset comprising seven Malaysian hawker food classes and measure calorie estimation accuracy. This objective was comprehensively addressed through the performance evaluation detailed in Section 5.3. The system was tested on the seven selected classes: Nasi Lemak, Roti Canai, Satay, Laksa, Popiah, Kaya Toast, and Mixed Rice. The CNN model achieved an average accuracy of approximately 80% across all classes, with Satay achieving the highest F1-Score of 0.83 and all classes maintaining balanced precision and recall metrics. The confusion matrix analysis revealed that misclassifications primarily occurred between visually similar items, such as Popiah and Kaya Toast, providing valuable insights into the challenges of Malaysian food recognition. Calorie estimation accuracy was validated through the dynamic portion sizing system, which calculates Food-to-Plate Ratios to adjust base caloric values from the Malaysian Food Composition Database.

In summary, this project has successfully delivered a functional prototype that automates the recognition and calorie estimation of Malaysian hawker food. The hybrid approach combining classical segmentation with deep learning classification provides both accuracy and interpretability, making it a viable tool for dietary monitoring applications.

## 6.2 Future Improvements

While the current system demonstrates strong performance, several enhancements could further improve its accuracy, usability, and real-world applicability.

The current system recognizes only seven Malaysian hawker food classes. Future work should expand the dataset to include a broader range of Malaysian cuisine, such as Char Kuey Teow, Nasi Goreng, Mee Goreng, Cendol, and Ais Kacang. Additionally, incorporating regional variations of existing dishes would improve the model's robustness. A larger and more diverse dataset would reduce intra-class variance issues and improve generalization across different restaurant presentations and lighting conditions.

The current prototype operates as a desktop MATLAB application, which limits accessibility for everyday users. A natural progression would be to deploy the system as a mobile application for iOS and Android platforms. This would involve converting the trained SqueezeNet model to a mobile-compatible format such as TensorFlow Lite or Core ML, and redesigning the user interface for touch-based interaction. Mobile deployment would enable real-time food analysis at hawker centers and restaurants, maximizing the system's public health impact.

Future versions could also integrate with popular health and fitness applications such as MyFitnessPal, Samsung Health, or Apple Health. This integration would allow users to automatically log their calorie intake from hawker food meals, enabling long-term dietary tracking and personalized nutritional recommendations. Application Programming Interface connectivity would facilitate seamless data exchange between the food recognition system and existing health ecosystems.

Another improvement involves multi-food detection and individual component classification. The current system classifies the entire plate as a single dish category due to the extensive training time required for object detection models and limited computational resources during development. Future work could incorporate object detection algorithms such as YOLO or Faster R-CNN to identify and count individual food items on a single plate. For instance, the system could count the number of satay skewers or distinguish between rice, chicken, and vegetables in a Mixed Rice dish, enabling more precise calorie calculations based on the actual quantity and composition of each meal. Additionally, depth estimation using stereo vision or structured light could provide more accurate volume-based portion calculations, moving beyond the current area-based approach.

Extending the system from static image processing to real-time video analysis would further enhance usability. Users could simply point their camera at a meal and receive instant nutritional feedback without manually capturing and uploading images. This would require optimization of the inference pipeline for speed and the implementation of frame-by-frame tracking to maintain consistent predictions.

Finally, while SqueezeNet provides a good balance between accuracy and efficiency, newer architectures such as EfficientNet, MobileNetV3, or Vision Transformers could potentially achieve higher accuracy with similar or lower computational requirements. Transfer learning from food-specific pretrained models, rather than general ImageNet weights, could also improve performance on the unique visual characteristics of Malaysian cuisine.

These future directions would transform the current proof-of-concept prototype into a comprehensive dietary monitoring solution capable of supporting public health initiatives and empowering Malaysians to make informed nutritional choices when enjoying their cultural culinary heritage.

A hybrid Deep-SVM approach, which combines high-level CNN features with the decision boundary precision of SVM classifiers, remains a promising avenue for future work that could potentially combine the strengths of both paradigms. Although initially explored, this ensemble method requires further optimization and computational resources to fully realize its performance benefits over standalone models.
